# 产品设计

> 来源：`docs/招投标信息平台-产品设计.html`（高保真视觉原型，1440×900 基准）
> 本文件把原型固化为可实现的字段、交互与视觉规范。

## 1. 设计风格

企业级后台控制台：严谨、克制、数据密度高。

- 浅灰底 `#EEEEEE` + 白色卡片 `#FFFFFF` + 品牌蓝 `#0052D9` 点缀
- 圆角极小（控件 3px / 卡片 6px）
- 无渐变、无阴影堆砌，靠**色彩语义与对齐**建立层级
- 微反馈为主：hover 变色、表格行分隔线、开关滑动；不使用大范围动效

## 2. 设计 Token

### 2.1 颜色

```css
--brand:        #0052D9;   /* 品牌蓝：主按钮、链接、选中态 */
--brand-hover:  #0046BB;
--brand-bg:     #F2F3FF;   /* 选中态浅蓝底 */
--bg-page:      #EEEEEE;   /* 页面底色 */
--card:         #FFFFFF;   /* 卡片 */
--th-bg:        #F3F3F3;   /* 表头底 */
--text-1:       #1A1A1A;   /* 主文本 */
--text-2:       #666666;   /* 次要文本 */
--text-3:       #999999;   /* 辅助文本/占位符 */
--border:       #DEDEDE;   /* 描边 */
--row-line:     #E8E8E8;   /* 表格行分隔线 */
--success:      #2BA471;   --success-bg: #E3F9E9;
--warn:         #E37318;   --warn-bg:    #FFF1E9;
--error:        #D54941;   --error-bg:   #FFF0ED;
```

### 2.3 语义色使用规则

| 语义 | 用于 |
| --- | --- |
| 品牌蓝 `--brand` | 招标公告、主按钮、链接、选中态 |
| 成功绿 `--success` | 中标公告、推送成功、抓取成功数 |
| 警告橙 `--warn` | 变更公告、B 级站点、人工处理数 |
| 错误红 `--error` | 推送失败、抓取失败数、投标截止时间、停用操作 |
| 中性灰 | 全部类型、其他、次要信息 |

## 3. 通用外壳（5 页共用）

### 3.1 左侧栏（240px，白底）

- **Logo 块**（高 56px）：品牌蓝圆角方块「招」（28×28，`linear-gradient(135deg,#1C52D9,#0052D9)`）+「招投标信息平台」（15px/600）
- **菜单项**（高 40px，圆角 3px，间距 4px）：

| 图标 | 文案 | 路由 | 备注 |
| --- | --- | --- | --- |
| list | 公告列表 | `/announces` | 公告详情页也高亮此项 |
| bell | 订阅管理 | `/subscriptions` | |
| send | 推送记录 | `/push-logs` | |
| doc | 抓取日志 | `/crawl-logs` | |

- 选中态：浅蓝底 `--brand-bg` + 左侧 3px 蓝条 + 蓝色文字 500 字重
- 未选中：透明底 + `#666` 文字；hover 底色 `#F5F5F5`

### 3.2 顶栏（56px，白底）

```
左：面包屑（14px，--text-3）      右：铃铛图标 → 竖分隔线 → 蓝色圆形头像「陈」→「陈钢」
```

面包屑规则：

| 页面 | 面包屑 |
| --- | --- |
| 公告列表 | 首页 / 公告列表 |
| 公告详情 | 首页 / 公告列表 / 公告详情 |
| 订阅管理 | 首页 / 订阅管理 |
| 推送记录 | 首页 / 推送记录 |
| 抓取日志 | 首页 / 抓取日志 |

头像 28×28 圆形，`--brand` 底 + 白色文字（静态展示「陈钢」，MVP 无登录）。

### 3.3 内容区

灰底，24px 内边距；结构：标题行 → 卡片（纵向 16px 间距）。
标题行 = 左（页面标题 20px/600 + 数据来源说明 12px `--text-3`）+ 右（页面级按钮）。

## 4. 页面 1 · 公告列表 `/announces`

- **面包屑**：首页 / 公告列表
- **标题行**：「公告列表」+「数据来源：bid_announce · 今日新增 N 条」

### 4.1 筛选卡（两行）

| 行 | 控件 |
| --- | --- |
| 上行 | 关键词输入框（220）+ 地区下拉（140）+ 公告类型下拉（140） |
| 下行 | 发布时间范围（240）+ 蓝色「查询」按钮 + 白底「重置」按钮 |

- 下拉默认值：「全部地区」「全部类型」
- 关键词 placeholder：`请输入公告标题关键词`
- 时间范围格式：`YYYY-MM-DD ~ YYYY-MM-DD`

### 4.2 表格卡

| 列 | 宽度 | 说明 |
| --- | --- | --- |
| 公告标题 | flex | 蓝色可点，超出省略；点击进详情 |
| 类型 | 88 | 语义 Tag |
| 采购人 | 150 | 超出省略 |
| 地区 | 90 | |
| 预算（万元） | 110 | 右对齐数值，千分位 + 2 位小数；空显示「—」 |
| 发布时间 | 110 | `YYYY-MM-DD`；`--text-2` |
| 操作 | 80 | 「查看详情」链接 |

### 4.3 分页行

左：「共 N 条记录 · 每页 20 条」
右：页码（24×24，当前项蓝底白字）+ `···` 省略号 + 下一页箭头

## 5. 页面 2 · 公告详情 `/announces/{id}`

- **面包屑**：首页 / 公告列表 / 公告详情（侧栏仍高亮「公告列表」）

### 5.1 标题区

- 标题 18px/600 + 类型 Tag
- 右侧：「查看原文」白底按钮（跳转 `detail_url`，新窗口）
- 下一行 12px `--text-3`：`来源：{source_site} · 发布时间：{publish_date YYYY-MM-DD HH:mm} · 公告编号：{announce_no}`

### 5.2 基本信息卡

标题「基本信息」（16px/500）；字段栅格两列，每列 350px，间距 24px：

| 字段 | 来源 | 样式 |
| --- | --- | --- |
| 采购人 | `purchaser` | 常规 |
| 预算金额 | `budget` | **加粗**，`X,XXX.XX 万元` |
| 投标截止时间 | `structured.deadline` | **错误红**，附「（剩余 N 天）」 |
| 代理机构 | `structured.agency` | 常规 |
| 联系人 | `structured.contact_person` | 常规 |
| 联系电话 | `structured.contact_phone` | 常规 |

标签 12px `--text-3`，值 14px `--text-1`。缺失显示「—」。

### 5.3 正文摘要卡

- 标题行：「正文摘要」+ 右侧 12px 灰字注「结构化字段提取自 bid_detail.structured」
- 正文：14px / 行高 24px，多段落（`structured.summary`）
- 无摘要时显示空态：「暂无结构化摘要」，并可回退展示 `content_text` 前若干字

## 6. 页面 3 · 订阅管理 `/subscriptions`

- **标题行**：「订阅管理」+「数据来源：bid_subscription · 已启用 N / 共 M 条订阅」，右侧蓝色「新建订阅」按钮

### 6.1 表格卡（无分页）

| 列 | 宽度 | 说明 |
| --- | --- | --- |
| 订阅名称 | flex | `name` |
| 关键词 | 170 | `keyword`，多关键词用 `/` 分隔；空显示「不限」 |
| 地区 | 90 | `region`；空显示「不限」 |
| 公告类型 | 100 | `announce_type` Tag；空显示「全部类型」（中性灰 Tag） |
| 推送渠道 | 130 | `channel` 中文映射 |
| 状态 | 90 | Switch（36×20），启用蓝 / 停用灰 |
| 操作 | 120 | 「编辑」+「停用」/「启用」；停用用错误红 |

### 6.2 新建 / 编辑弹窗

| 字段 | 控件 | 校验 |
| --- | --- | --- |
| 订阅名称 | Input | 必填，≤128 字 |
| 关键词 | Input | ≤255 字，多个用 `/` 分隔，空 = 不限 |
| 地区 | Select | 空 = 不限 |
| 公告类型 | Select | 空 = 全部类型 |
| 推送渠道 | Select | `feishu_webhook` / `email` / `webhook` |
| Webhook 地址 | Input | 必填，合法 URL，≤1024 字 |

校验错误在字段下方行内红字显示，提交前阻止。
开关切换即时生效（乐观更新，失败回滚并提示）。

### 8.1 表格卡

| 列 | 宽度 | 说明 |
| --- | --- | --- |
| 执行时间 | 130 | `run_at`，`YYYY-MM-DD HH:mm`，`--text-2` |
| 源站 | 190 | `source_site` + 站点等级小标签（A级绿 / B级橙 / C级灰，20px 高） |
| 抓取总数 | 100 | `total` |
| 成功 | 80 | `success`，绿色 500 字重 |

| 备注 | flex | `note`，`--text-2`，超出省略 |

### 8.2 分页行

同公告列表（每页 20 条）。

## 9. 交互与状态

### 9.1 通用

| 状态 | 表现 |
| --- | --- |
| 加载 | 表格区域骨架屏 |
| 空数据 | 空态组件：图标 + 「暂无数据」+ 说明文案 |
| 接口错误 | 卡片内错误提示 + 「重试」按钮 |
| 筛选无结果 | 空态文案「没有符合条件的公告，试试调整筛选条件」 |

### 9.2 链接与按钮

- 可点击文本 hover 加下划线
- 主按钮 hover `#0046BB`；默认按钮 hover 边框与文字转品牌蓝
- 开关点击即切换，带 200ms 滑动过渡

### 9.3 数值为 0 的处理

抓取日志中「成功 / 失败 / 人工处理」为 0 时降低视觉权重（用 `--text-3` / `--text-2`），
避免整屏红绿。

## 10. 响应式

- 桌面优先，1440 基准
- < 1200px：侧栏收窄至 200px，表格横向滚动
- 移动端仅保证卡片与表格可读，不做独立布局
